**Architecture:**
```
┌────────────────────────────────────────────┐
│         RAILWAY CLOUD (24/7)               │
│  Cloud Agent: Draft-Only Domain            │
│  ├── Gmail → Draft replies                 │
│  ├── Facebook → Draft posts                │
│  └── Instagram → Draft posts               │
└────────────────┬───────────────────────────┘
                 │ Git Sync
┌────────────────┴───────────────────────────┐
│         LOCAL MACHINE (User Present)       │
│  Local Agent: Full Domain + Approvals      │
│  ├── Pull Cloud drafts                     │
│  ├── User approves (HITL)                  │
│  ├── Execute: Send email, Publish posts    │
│  ├── WhatsApp, Banking (secure)            │
│  └── Push completions → Cloud audit        │
└────────────────────────────────────────────┘
```
